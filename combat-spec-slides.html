1. RNG 시드 스트림

P1-1

같은 입력이면 같은 결과 — 리플레이·시뮬레이션·연출이 전부 이 토대 위에서 파생된다.

CombatRng

seed uint64챕터 진입 시 1회 고정. 웨이브 전환에도 스트림 연속
streamPCG/xorshift 등 결정론적 시퀀스
next() float[0, 1) 반환

시드 소스 — 실플레이: 시각·유닛 구성 해시에서 파생(패배 재시작 시 새로 파생). 시뮬레이터: 명시적 주입.

호출 규율 — 재현성의 전부

  • 재현성: 동일 (편성+배치+적 덱+seed) → 완전히 동일한 전투 결과
  • 치명타 판정: 정산 순서(P7)대로 대상별 정확히 1회
  • AI 타겟 추첨: 타겟 확정 단계에서 정확히 1회. 후보 열거 = 슬롯 순 고정
  • 광역: 열거·정산·RNG 소비 전부 F1→F2→F3→B1→B2→B3 고정
  • 후보 집합 산출 = 순수 함수(RNG 미사용)
  • RNG 미소비: 확정 치명타 · 후보 1명 · HP 최저 등 결정론적 선정 · 도발 강제

1. 스탯

P2-1

스킬을 코드가 아니라 데이터로 — 캐릭터 추가는 기획자의 조립 작업이어야 콘텐츠 속도가 유지된다.

StatBlock — 공식 7종 · 회피/명중 없음

atk / def int공격력 / 방어력
hp int최대 체력(현재 HP는 런타임 상태)
critRate float치명타 확률 0~1. 게임 내 유일한 확률 판정
critDmg float치명타 피해(배율 가산분, 0.5 = +50%)
critRes float치명 저항 — 확률 차감 아님, 피해량 상쇄
spd int행동 속도. 턴 순서 결정자

정수 저장 원칙, 확률·계수만 소수 허용. 모든 공격은 명중한다.

클램프 — effective 산출 마지막 1회 · base 불변

critRate0 ~ 1
critDmg · critRes · atk · def · elementDef하한 0
spd하한 1 (행동 불능 영구화 방지)
hp(최대)하한 1
  • 최대 체력 증가: 현재 HP 유지(회복 없음) — HP 비율만 하락
  • 감소·만료: currentHp = min(currentHp, 새 최대)

2. 버프/디버프 합산 — 계산 그룹

P2-2

meta.calcGroup — 효과 데이터에 지정(전역 고정 아님)

ADD_FLAT고정값 가감 — 같은 스탯끼리 단순 합산
ADD_PERCENT가산 퍼센트 — 전부 더한 뒤 1회 곱
MUL독립 곱연산 — 인스턴스마다 개별 곱(별도 승수)
effective = (base + Σ ADD_FLAT)
          × (1 + Σ ADD_PERCENT)
          × Π (1 + MUL_i)

규칙

  • 예) base atk 120 + 30%(ADD_PERCENT) → 156. 별도 MUL +20% → 156 × 1.20 = 187
  • 합산은 같은 스탯 키 안에서만 이뤄진다
  • 피해 감쇄(보호)의 곱연산은 이 파이프라인과 별개
  • 클램프는 effective 산출의 마지막 단계 1회

9. 중첩 규칙

P2-9

StackRule & 그룹 키

ruleIGNORE · SEVERAL · OVERRIDE · STACK
groupKey?동일 효과 판정 키. 미지정 시 자동 파생
maxStack?STACK 전용, 1 이상
  • 자동 파생 = type + 구분 필드 (STAT_MODIFIER: stat+calcGroup+direction)
  • 기본은 시전자 미포함(누가 걸든 같은 효과)
  • 예외: TAUNT·DAMAGE_REDUCTION은 키에 시전자 포함 + OVERRIDE — 시전자 다르면 공존, 같으면 갱신
  • 중첩 규칙은 같은 그룹 키 안에서만 적용

4종 규칙 — 예: "공격력 +10" 2회 유입

IGNORE신규 미적용. 지속·수치 그대로 → +10 하나
SEVERAL별도 인스턴스 추가, 각자 만료 → +20, 각자 소멸
OVERRIDE기존 제거·교체, 새 수치·지속 재시작 → +10 새로
STACK스택 +1(max 멈춤) · 지속 재시작 · 수치 = value×스택 → 스택2 = +20

즉발 효과(DAMAGE·HEAL)에 stack 무의미. STACK이면 maxStack ≥ 1 필수.

  • 플레이어와 AI가 타겟팅 로직 공유 — AI는 "후보에서 고르는 규칙"만 얹음

P5-3

기본 앞열 규칙

  • ENEMY_SINGLE 후보 = 상대 유효 앞열
  • 앞열 공집합 → 뒷열 자동 전환
  • 광역은 이 규칙 무관 — 지정 범위 생존자 전원

뒷열 명시

  • 뒷열도 공집합이면 폴백 없음 — 발동 불가(P5-5). 수동 전투라 플레이어가 다른 스킬 선택

4. 도발 강제

P5-4

강제 범위 — 모든 단일 대상 공격

  • 광역·회복·버프에는 영향 없음
  • 예외: targeting.ignoresTaunt = true 스킬은 강제 안 받음(저격·처형 컨셉, 데이터 지정)

적용 시점 & 다중 도발

  • 적용 = 타겟 확정 직전. 이 시점에 도발자 생존을 실시간 재조회(턴 진입~확정 사이 사망 가능)

5. 조건부 선정 · 입력 주체 · 타겟 없음

P5-5

조건부 선정 & 입력 주체

  • LOWEST_HP 계열 = 선정 시점 HP 비율 최저. "가장 약한 적" 같은 중의적 표현 금지
  • 동률: 앞열 우선 → col 낮은 순 → ID 순
  • 아군 = 플레이어가 후보 집합에서 UI로 선택 / 몬스터 = AI 정책
  • 강제 규칙 있으면 그 안에서만 선택

타겟 없음 · 자기 포함

  • 유효 타겟 0 = 발동 불가 — 아군은 버튼 비활성, 몬스터는 다음 우선순위로. 일반 공격도 대상 없으면 무행동 턴

  • 광역은 1명이라도 있으면 발동
  • 자기 포함은 스코프가 명시: ALLY_*(제외) / ALLY_INCL_SELF_*(포함) / SELF. 스킬 설명 문구도 이를 구분

1. 발동 가능 판정 & 선택 주체

P6-1

아군 스킬 선택은 온전히 플레이어의 몫 — 쿨타임이 "언제 아낄 것인가"의 리듬을 만든다.

발동 가능 판정 — 순수 함수, 아군 UI·몬스터 AI 공유

발동 가능 = 잔여 쿨 0
        AND 발동 조건 충족 (trigger 있을 때)
        AND 유효 타겟 존재
  • 일반 공격은 쿨·조건 없음 — 대상만 있으면 항상 가능
  • 패시브 슬롯은 판정 대상 아님(트리거로 별도 발동)

선택 주체 — 수동 전투의 핵심

아군발동 가능 슬롯 집합을 UI 노출(불가 슬롯 비활성) → 플레이어가 직접 선택
몬스터스킬2 → 스킬1 → 일반 순 평가, 발동 가능한 첫 스킬 자동 사용. 존재 슬롯만 순회

전부 불가면 일반 공격이 최종 폴백. 일반 공격조차 대상 없으면 무행동 턴 종료.

2. 쿨타임 — 부여 · 감소 · 초기

P6-2

부여 & 감소 — 자기 턴 기준 · 턴 종료 처리 한 곳에서만

  • 사용 시: 그 액티브에 cooldown 값 부여
  • 자기 턴 종료 시: 방금 사용한 스킬 제외 나머지 액티브 −1(0에서 멈춤) — 포함하면 실효 쿨 1 감소
  • 스킵 턴 = 사용 스킬 없음 → 전부 −1
  • 쿨 3 = 사용 턴 제외, 자기 턴 종료 3번 후 4번째 자기 턴에 재사용

초기 쿨타임

  • "초기 쿨 N" = 전투 시작(챕터 진입) 시 잔여 쿨 = N
  • 웨이브 전환 시 재적용 없음 — 잔여 쿨 유지(P9)
  • 초기 0 → 1라운드 즉시 사용 / 초기 1 → 자기 턴 1회 후
  • 검증: initialCooldown ≤ cooldown

평가 위치 — 자기 턴 선택과 무관

PHASE 7 · 효과 & 데미지

1. 단일 DAMAGE 정산 순서

P7-1

한 대의 피해가 만들어지는 서사 — 순서가 고정되어야 플레이어가 피해량을 예측·역산할 수 있다.

7단계 — 대상은 P5에서 확정된 상태로 진입

1기본 피해 — atk × 계수 vs 대상 def
2치명 판정 — 유일 확률. guaranteedCrit은 RNG 미소비
3속성 보정 — 추가 배율 합 − 속성 방어 합(디버프 반영)
4보호 감쇄 — REDUCTION 곱연산 · 위치 조건 실시간 판정
5반올림 & 하한 — ROUND 후 최종 1회 max(1, ·)
6흡혈 적립 — 확정 피해 × 비율(회복은 아직 미적용)
7HP 적용 — currentHp 감소, 0 클램프

곱연산 체인

기본
 × 치명 보정
 × 속성 보정
 × (보호 감쇄 곱)
 → ROUND
 → max(1, ·)

HEAL은 1~4 생략(치명 없음) → 회복량 산출 → 적용 → 후처리 3~5. 비피해 효과(버프·도발·면역)는 부여 즉시 후처리 3~5만.

PHASE 7 · 효과 & 데미지

2. 광역 처리 & 정산 후 처리

P7-2

정산 후 처리 5단계 — 효과 하나 완료 시점 · 다음 효과 전 완결

1사망 판정 — 동시 사망: 타격 시작 스냅샷으로 1~5 후 일괄 처리. "타격" 단위 = 효과 1회 정산(다단 히트는 히트 간 사망 반영)
2흡혈 회복 반영 — 초과 버림. 시전자 사망 시 무효(적립 소멸)
3REALTIME 패시브 재평가 — 1패스만. 연쇄는 다음 정산에서 수렴
4파생 트리거 — ON_ATTACK_LANDED·CRIT·KILL. 광역은 명중 수만큼 슬롯 순
5spd 변동 시 즉시 재정렬(P4-3)

앞 효과가 만든 사망·버프가 뒤 효과에 반영된다.

광역 처리

  • 대상마다 1~5 개별 수행(위치·감쇄·치명 각자 판정, 슬롯 순)
  • 6에서 흡혈 전 대상 합산 → 7 HP 일괄 적용
  • 정산 후 처리는 광역 효과 전체에 1회
  • 단, 파생 트리거는 명중 대상 수만큼 슬롯 순 개별 발동
PHASE 7 · 효과 & 데미지

3. 데미지 공식 · 치명 · 속성

P7-3

공식 — 구조·순서 확정 · 계수는 밸런싱 조정 대상

# 감산율 방식 · k_def = 300 (임시)
방어 경감 = def / (def + k_def)          # 0~1
기본     = atk × 계수 × (1 − 방어 경감)

치명 보정 = 1 + critDmg − 대상 critRes  # 비발동 시 1
속성 보정 = 1 + Σ(추가 배율 − elementDef) # 하한 0
감쇄 배율 = Π(1 − REDUCTION 값)

최종 = max(1, ROUND(기본 × 치명 × 속성 × 감쇄))

ROUND = 사사오입(0.5는 0에서 먼 쪽) 고정. 연산 정밀도·항 순서(좌→우)도 클라·시뮬 동일 고정 — 재현성.

치명 & 속성

  • 치명 = 게임 내 유일 확률. rng.next() < critRate, 대상별 1회
  • critRes는 확률 아님 — 치명 피해량 상쇄
  • 이벤트: 발동 CRIT / 비발동 HIT
  • 속성 이점 = 속성 방어 디버프(별도 규칙 없음)
  • elementDef > 배율이면 보정 < 1 가능 — max(1) 하한 유지
  • 무속성 스킬 = 보정 1(속성 방어 미적용)
  • 2속성 = 속성별 (배율 − def) 각각 계산 후 합산
PHASE 7 · 효과 & 데미지

4. 회복 · 버프/디버프

P7-4

회복

  • 회복량 = 시전자 atk × 계수. 치명 없음(RNG 미소비)
  • 초과 회복 버림: min(최대, current + 회복량)
  • 흡혈: 확정 피해 × lifestealRatio 적립 → 후처리 2단계에서 시전자 회복. 광역은 합산 1회. 시전자 사망 시 무효
  • 사망자 회복 불가(부활 없음). 이벤트: HEAL

버프/디버프 지속

  • 부여: 중첩 규칙으로 인스턴스 확정 → 계산 그룹으로 합산
  • 감소: VICTIM_TURN = 대상 턴 종료 −1 / CASTER_TURN = 시전자 턴 종료 −1 → 0이면 만료(STAT_MODIFIER_EXPIRED)
  • effective는 부여/만료 즉시 갱신, spd 변경 시 재정렬
PHASE 7 · 효과 & 데미지

5. 도트 & 면역

P7-5

도트 — 기본 중첩 SEVERAL(독립 누적·독립 만료)

  • 틱 시점: 대상 턴 종료 처리에서 발동(1회=1틱) 후 remaining −1
  • 틱과 감소는 항상 쌍 — "N턴 도트 = 정확히 N틱" 불변식
  • 부여 라운드 예외: 대상이 이미 행동을 마쳤으면 → 그 라운드 내 첫 피격 시 즉시 1틱 + remaining −1. 피격 없으면 틱·감소 없음 — 다음 라운드부터 정상(틱 소실 없음, 만료만 1라운드 지연). 이 판정 시 DOT_PENDING 방출
  • 틱 피해 = DAMAGE 파이프라인 재사용, 치명 없음(RNG 미소비). 속성·감쇄 적용
  • 해로운 효과 → 면역 차단 대상. 시전자 사망해도 유지

면역 (P2-10 요약)

  • category 일치 해로운 지속 효과의 신규 부여 차단 → IMMUNITY_BLOCK
  • 기부여 동종 도트의 틱 차단(잔여 감소는 진행)
  • 즉발 피해·회복은 무관
  • 지속은 주로 VICTIM_TURN 기준
PHASE 7 · 효과 & 데미지

6. 보호 · HP 트리거 · 동시 사망

P7-6

보호 = 감쇄 + 도발

  • 감쇄: 위치 조건 매 피격 실시간 판정 · 곱연산 — 15%+30% → 1−(0.85×0.70) = 40.5%
  • 보호 주체 사망 시 즉시 소멸(동시 사망은 스냅샷 적용)
  • 중첩: 키에 시전자 포함 + OVERRIDE — 시전자 다르면 공존
  • REDUCTION_APPLIED value = 감쇄 전−후 차(흡수량), source = 보호 시전자, 피격당 1회

HP 트리거 패시브

  • HP_THRESHOLD = REALTIME — 진입 즉시 적용, 이탈 즉시 해제. 평가는 후처리 3단계
  • 자기 HP 패시브(각성 on/off)와 적 HP 타겟 선정은 별개 개념
  • 경계 오르내리면 매번 적용/해제 + spd 재정렬

동시 사망

  • 스냅샷 → 개별 피해 확정 → 일괄 사망 → 흡혈 반영 → REALTIME 재평가 → 파생 트리거 → 재정렬
  • 보호 주체·피보호가 같은 타격에 죽어도 그 타격엔 보호 적용
  • "같은 타격" = 같은 효과 1회 정산 — 다단 히트는 히트 간 사망 반영
PHASE 8 · 몬스터 AI

1. 스킬 선택 & 타겟 정책

P8-1

몬스터는 "읽을 수 있는 위협" — 정책 기반 패턴 학습의 재미 + 정보 비공개의 추론 게임.

AiPolicy — targeting.aiPolicy 오버라이드 · 도발 강제 최우선

THREAT_WEIGHTED (기본)가중치 = 선정 시점 effective atk · 확률 = w/Σw — RNG 1회
RANDOM후보 균등 추첨 — RNG 1회
LOWEST_HP후보 중 HP 비율 최저(동률은 P5-5) — RNG 0회
BACKLINE_FIRST후보에 뒷열 있으면 뒷열만 → THREAT_WEIGHTED — RNG 1회
FIXED_ROLEmeta.role(Class) 우선 → THREAT_WEIGHTED. 없으면 전체 폴백 — RNG 1회

RNG는 타겟 확정 단계 정확히 1회 · 후보 열거 슬롯 순. 결정론적 선정(후보 1명·LOWEST_HP·도발)은 RNG 미소비. 예) 고블린 도적 기습 = BACKLINE_FIRST.

스킬 선택

  • 몬스터도 스킬2→1→일반 자동 선택(P6)과 발동 판정·쿨 그대로

PHASE 12 · UI/UX

1. 편성 · 전투 화면 · 타겟 선택

P12-1

"보는" 전투 — 배속은 허용, 스킵은 없다. 매 턴의 선택과 연출이 곧 콘텐츠다.

편성 UI

  • 전투 진입 전 매번 노출
  • 1~5명 선택 + 2×3 배치 · 마지막 설정 유지
  • 편성 검증(P3-1) 위반 시 진입 차단

전투 화면

  • 양 진영 그리드(빈 칸 포함) · 턴 순서(아군만 정확, 적은 마스킹)
  • 아군 HP 수치 / 적 HP는 비율 바 또는 숨김
  • 상태 아이콘 = 효과 인스턴스 수명 종속 · STACK/SEVERAL 수 뱃지

타겟 선택

  • 발동 가능한 스킬 버튼만 활성(불가 시 비활성 + 사유)
  • 스킬 선택 → 후보 하이라이트 → 탭으로 대상 선택
  • 강제(도발)면 후보 1개로 표시 · 광역은 범위 프리뷰
