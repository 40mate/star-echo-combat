1.1편성
기본 규칙
  • 인원: 최대 5명 / 최소 1명 (보유 동료 수와 무관)
  • 그리드: 2×3 (앞열 3 / 뒷열 3) UI
  • 빈 칸 위치는 플레이어가 자유 선택
  • 사망 캐릭터는 해당 칸에서 제거, 빈 칸은 공석 유지 (자동 이동 없음)
  • 포지션 기반 보호 효과는 위치 조건 충족 시 자동 발동. 보호 주체 사망 시 즉시 소멸
  • 타겟 선정: 아군 캐릭터의 타겟은 플레이어가 매 턴 직접 선택한다. 몬스터는 자체 AI 룰에 따라 자동 선정.

1.2속성
  • 캐릭터는 고유 속성을 가진다.
  • 일반 공격 / 스킬1 / 스킬2 각각에 최대 2개의 속성을 부여할 수 있다.
  • 속성 5종: 불 물 풀 빛 어둠
  • 상성·약점 시스템은 없으며, 추가 데미지 + 속성 방어의 상호작용으로 계산된다.
1.3클래스
  • 4종: 방어 / 근거리 딜러 / 원거리 딜러 / 서포터
  • 클래스 간 상성은 없다.
  • 클래스 ↔ 스킬 상호 유추 가능 — 클래스를 보면 스킬 성격을 알 수 있고, 스킬을 보면 클래스를 알 수 있다.
1.4행동 / 턴
  • 모든 캐릭터는 행동 속도(정수)를 가진다.
  • 1턴 = 캐릭터 1명의 행동. 가장 높은 행동 속도부터 순차 진행.
  • 행속 동률 처리: 아군 우선 → 레벨 높은 순 → 전투력 높은 순 → 캐릭터 ID 순
  • 행동 속도는 전투 중 외부 요인에 실시간 반응하여 순서 조정 가능.
  • 단, 이미 행동을 마친 캐릭터는 현재 사이클의 순서 변경 대상에서 제외된다.
  • 1사이클 (최고 → 최저 행동속도 1바퀴) = 1라운드.
1.5스킬
  • 3슬롯: 일반 공격 / 스킬1 / 스킬2
  • 스킬1, 스킬2는 각각 액티브 또는 패시브로 자유 구성. 단, 둘 다 패시브일 수는 없다.
  • 자기 턴 우선순위: 조건 충족 스킬2 → 스킬1 → 일반 공격
  • 액티브 스킬은 턴 단위 쿨타임을 가지며, 초기 쿨타임 별도 지정 가능.
  • 쿨타임 카운트: 해당 캐릭터의 자기 턴 기준. 쿨 N = 스킬 사용 후 자기 턴 N회 경과 시 재사용 가능.
  • 초기쿨 N = 전투 시작 시 이미 N턴 소모된 상태로 진입. 예: 초기쿨 0 → 1라운드부터 즉시 사용 가능.
  • HP 조건 트리거 패시브는 실시간 적용 — HP가 조건에 닿는 순간 발동, 벗어나는 순간 해제.

데미지 공식 (시뮬레이션 검증용 임시, 추후 조정 예정)
기본 데미지 = max(1, 공격력 × 스킬계수 − 방어력)
치명타 보정 = 발동 시: (1 + 치명타피해 − 치명타저항)
비발동 시: 1
속성 보정 = 1 + Σ(추가배율 − 속성방어)
최종 데미지 = max(1, ROUND(기본 × 치명타보정 × 속성보정))
  • 2속성 부여 시 각 속성별 보정을 모두 합산
  • 속성 추가 배율 기본값: 1속성 +0.3 / 2속성 +0.6
  • 속성 방어 기본값: 0
1.7몬스터 / 보스
  • 플레이어 공개 정보: 스킬 목록만. HP 수치와 사용 순서는 비공개.
  • 보스 페이즈 / 즉사기 등 별도 시스템 없음 — 모두 일반 스킬로 구현.
1.8전투 종료 / 진행
종료 조건 & 결과
  • 종료 조건: 한쪽 진영 전멸만
  • 부활 스킬: 미기획 (필요 시 추가 가능)
  • 전투 종료 시 HP / 쿨타임 전부 회복 — 매 전투는 독립적
  • 패배 페널티 없음. 패배 시 일상 페이즈로 복귀, 클리어 전까지 스토리 미진행
구조 & UX
  • 24챕터 × 챕터당 1전투 구조, 회차 반복 시 재플레이
  • UX: 배속 O, 스킵 X, 자동전투 X
  • 전투 진입 전 편성 UI 매번 노출 (마지막 설정 유지)
1.9효과 / 상태이상
  • 도트(지속 피해)는 중첩 가능. 동일 시전자·속성·스킬 여부 무관, 각각 독립 누적.
  • 도트는 해로운 효과로 분류, 면역 효과의 차단 대상에 포함.
  • 면역은 지정 종류의 신규 효과 부여를 차단하고, 이미 부여된 동종 효과의 발동도 차단.
  • N턴 디버프/버프: 대상 캐릭터가 N번의 자기 행동을 마칠 때까지 지속 (다른 단위가 필요한 효과는 스킬 설명에 별도 명시).
  • 도트 데미지는 대상의 턴 종료 시점에 적용된다. 단, 도트 부여 시점 이전에 해당 라운드 행동을 이미 마친 캐릭터는, 해당 라운드 내 첫 번째 피격 시점에 도트를 1회 즉시 발동한다.

속성 통일성 — 4종 모두 어둠 계열로 통일. 챕터 컨셉이 '언데드/암흑 진영'. → 빛·풀 속성 캐릭터가 추가 데미지 이점을 가짐.

역할 분리 — 일반(근접/원거리) → 엘리트(서포터) → 보스(방어)로 클래스가 겹치지 않도록 구성.

보스의 즉사기·페이즈 대체 — '불멸의 의지' 패시브 하나로 "HP가 낮아질수록 더 어렵다"는 후반 압박을 표현. 발동 임계값 15%, 공격력 +26%.
